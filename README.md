# ProofFlow clean starter

This is a clean React + Vite static frontend starter using the actual LightPillar component source supplied from React Bits.

## Run on Windows

1. Extract this ZIP to a new folder, for example `C:\Users\rsuba\proof-flow-clean`.
2. Open that folder in VS Code.
3. Open the VS Code terminal and run:

   ```powershell
   npm.cmd install
   npm.cmd run dev
   ```

4. Open the local URL Vite prints (usually `http://localhost:5173`).

If PowerShell blocks `npm`, use `npm.cmd` as shown. The existing `proof-flow` folder is not modified.

## Notes

- This is a static demo UI; no backend, login, database, or real payment integration is connected.
- The LightPillar component requires WebGL 2 support in the browser.
- Sample transaction names and amounts are placeholders.
